Независимый Hybrid-only проект. HSB.1 создал неторгующий MQL5-каркас: типы, контракты, validators, чистую FSM, no-trade stub, diagnostics и unit-test harness.

REAL_TRADING_ALLOWED=NO

Main: `Hybrid_Split_Big_Independent_EA.mq5`. Финальный отчёт: `Reports/HSB_STAGE_1_FINAL_ACCEPTANCE_RU.md`. До MetaEditor compile и запуска MQL5 unit tests переход к HSB.2 запрещён.
