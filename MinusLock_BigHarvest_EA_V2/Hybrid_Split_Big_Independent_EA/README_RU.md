Статус до финальной приёмки:

```text
HSB_STAGE_1_STATUS=READY_FOR_ACCEPTANCE
NEXT_ALLOWED_STAGE=NONE
AWAITING_FINAL_ACCEPTANCE=YES
TRADING_IMPLEMENTED=NO
REAL_TRADING_ALLOWED=NO
METAEDITOR_COMPILE=NOT_RUN_ENVIRONMENT_UNAVAILABLE
MQL5_UNIT_TESTS=NOT_RUN_ENVIRONMENT_UNAVAILABLE
```

Main: `Hybrid_Split_Big_Independent_EA.mq5`. Карта: `PROJECT_MAP_RU.md`. Нормативная база: Docs/03–19 и Docs/23. Trade API и старые include отсутствуют.
