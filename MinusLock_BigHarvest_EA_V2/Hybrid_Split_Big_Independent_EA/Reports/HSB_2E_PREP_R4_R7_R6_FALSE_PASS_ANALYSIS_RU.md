# Анализ ложных PASS R4-R6

Исполнимый runner сохраняет полный канонический вход и его SHA-256. Восемь семейств показывают взаимную подделку commit-state, незапечатанный residual, обратимые стороны цены, foreign snapshot, self-healing adapter и count-only semantic comparison.

Исторический R4-R6 сохранён без изменений; результаты этого отчёта являются основанием для `HISTORICAL_SUPERSEDED`.
