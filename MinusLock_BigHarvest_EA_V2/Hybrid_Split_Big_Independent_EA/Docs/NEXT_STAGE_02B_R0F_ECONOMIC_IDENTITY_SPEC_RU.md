Logical source key=(Broker,Server,AccountLogin,DealTicket), independently sourced. Payload SchemaVersion не создаёт новый экономический источник; unknown schema UNAVAILABLE. Physical codec/key version не повод для двойного funding одного logical deal. Symbol/Magic/Cycle не часть key: их изменение при прежнем source должно конфликтовать, а не создавать новый grant.

Профиль HSBI-EA-ECON-1 — attributed EA source. Manual/unknown magic0/cycle-less deals остаются economic observations для будущего полного account ledger, но не получают EA attribution по умолчанию. Этот узкий профиль не доказывает global account funding. Origin IDs/role/plan берутся из independent EA association journal, не comment/current terminal. Broker company display name сам по себе не является стабильным BrokerIdentity; provider binding требует evidence.

Receipt/correction/provenance verification envelopes отдельно от immutable body: повторное чтение тех же фактов с новым observation receipt не переписывает body. Corrected broker facts →CONFLICT для старого source и отдельный linked correction contract; никаких silent replace/NEW credit. SourcePlanApplicable/SourcePolicyApplicable=false требует доказанного NOT_APPLICABLE, не маскирует unknown.

Каждое поле обязательно в DTO; conditional origin ID может быть None только при verified NOT_APPLICABLE. Missing/invalid type REJECT; unknown required units/origin/schema UNAVAILABLE. Raw finite doubles сохраняются как наблюдённые значения с явно proposed Z-zero equivalence в двух codec-кандидатах; это не неизменённый broker network packet. Exact raw-byte packet, если нужен, хранится separately unchanged под independent receipt. No epsilon/DoubleToString8 для equality. Mutable valid/reconciliation flags не входят в immutable equality и не создают authority.

Same logical key + exact approved semantic payload =>NO_OP/zero delta; changed Profit/Commission/Swap/Fee/volume/price/role/time/units/EA origin =>CONFLICT даже при Net50. Foreign logical namespace =>NEW_IDENTITY_ONLY, не grant authorization. Кодек неизвестен или нет approved cross-version mapping =>UNAVAILABLE. Current ActorCycle/Plan/Revision/Snapshot не подставляются в historical source.

Serialization: fixed field order в CONTRACT_MATRIX и CODEC_GOLDENS; field type/length tags disjoint. Full native canonical decoder ещё NOT_RUN; Python fixture decoders только проверяют known golden payloads. R1.1 минимальный scope не вправе объявлять legacy serializer authoritative. Reconciliation независимых broker components/posted net — отдельный слой, не source-key validation.
