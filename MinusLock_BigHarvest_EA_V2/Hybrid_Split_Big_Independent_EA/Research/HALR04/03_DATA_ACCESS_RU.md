# Исторические Bid/Ask

Источником служит общедоступная серия HistData Generic ASCII Tick EURUSD с отдельными Bid и Ask. Формат использует фиксированный EST (UTC−05:00) без перехода на летнее время. Получены новые месяцы 2019–2025 и два архивных контрольных месяца HALR-03. Единственный поставщик ограничивает независимость по поставщику; независимость итогового теста относится к временным эпизодам. [Описание формата](https://www.histdata.com/f-a-q/)

Загрузка повторяется штатной формой провайдера через закреплённый HALR-03 fetch_histdata.py. Неизменённые исходные ZIP сохраняются локально. Манифест содержит ключи месяцев, ссылки и SHA-256. Условия перераспространения не подтверждены, поэтому архивы не включены в Git. При смене хэша анализ маркируется новой версией данных.

Чтение отслеживает обратное время, разные записи на одном timestamp, точные дубликаты, нулевой и отрицательный spread, ошибочную точность, выходы за сетку point, разрывы, внебиржевые календарные часы и скачки. Нулевой spread зарегистрирован и оставлен при отсутствии crossed. Длительные разрывы не интерполируются. Месяцы отделены по календарю заранее, перед расчётом доходности.
