# Recovery Decision Boundary

RDB-0 делегирует немедленному K. RDB-1 пробует замороженную A3-ER после независимой проверки. RDB-2 выбирает A3-ER или K по знаку учёта добавленной стоимости в предшествующих эпизодах. RDB-3 включает M-ER. RDB-4 требует положительной нижней границы оценки по блокам месяцев, не менее 16 пар и четырёх месяцев в страте, без нарушений и остатков у обучающих пар.

При активации признаки содержат только известные Bid/Ask, прошлый тридцатиминутный диапазон и направление движения относительно исходного замка. Таблицы обучаются по страте spread/волатильность/направление, затем по spread, затем общей выборке. Для RDB-2/3 нужно 8 пар из двух месяцев, средняя регуляризуется к нулю. Выбор маршрута выполняется один раз. Каждый последующий пакет повторно проверяется. Отказ возвращает EXIT_K только при независимом допуске на весь текущий выход. При pending обработка подтверждений предшествует новому действию.

Симуляция сохраняет OBSERVE, RISK_CHECK, DECIDE, ожидание ACK, PARTIAL/UNKNOWN/FILLED, RECONCILE и FLAT_CONFIRMED. Неизвестный остаток сохраняется. Режим NO_CERTIFIED_ACTION не создаёт виртуальной сделки. Полный технически доступный выход после уже зафиксированного нарушения записывается отдельно как UNCERTIFIED_REMEDIAL_EXIT. Данные текущего тестового маршрута не используются для назначения его политики.

Временный FLAT между закрытием исходной корзины и условным входом M-ER не завершает цикл автоматически. Закрытие цикла подтверждается по целевой ликвидации, истечению горизонта или отдельному решению EXIT. Дефект преждевременной остановки выявлен на validation и исправлен до блокировки моделей.
