# Причина четырёх нарушений HALR-01

Все четыре записи приходятся на один механизм persistent_failure в двух ориентациях и двух зеркалах. Настройки A3 при B=$180: Net 0.20, Core floor 0.25, trigger 140, switches 3, harvest 0.5, horizon 8, reserve 0. Первые два движения по ±300, затем противоположный гэп 4000 пунктов и три нулевых движения. Отказы действуют со второго события по последнее.

| Событие | Net в направлении первого движения | Gross | CyclePnL | Исполнение |
|---|---:|---:|---:|---|
| 0 | 0 | 2.00 | −58 | Ожидание |
| 1 | 0.20 | 1.80 | −58 | Доступно, сокращена встречная нога |
| 2 | 0.20 | 1.80 | +2 | Выход по цели отклонён |
| 3–6 | 0.20 | 1.80 | −798 | Выход недоступен |

−798 = 2 − 0.20×4000. Максимальная просадка $800. Оставшиеся 1.80 лота учитываются по оценке ликвидации, восстановление отсутствует. Задержка не включена в этот сценарий. Отказ сохраняет открытый риск, гэп превращает его в нарушение. Риск стал необратим после отказа на шаге 2 в рамках заданной последовательности. Закрытие было доступно на шагах 0 и 1. K, применённая к тем же внешним событиям, завершалась на шаге 0 с −$58 во всех четырёх случаях. Следовательно, нарушение условно на выбранном действии, а не неизбежно для каждой стратегии.

Источник зафиксирован в PR #6 по 0da896a615b47771d9cf66b6bf7c55cc782b74fc. В HALR-01 закрытие по неизменной котировке переносит mid-PnL в реализованную часть, а стоимость fill замещает резерв. Положительная плавающая оценка +$2 на шаге 2 не засчитана. Original Core проверен регрессионными тестами по идентификатору исходного билета.
