# Протокол

Номинальная модель использует D={−300,−150,0,150,300}. Предыдущее приращение повторяется с вероятностью 1/2, иначе выбор равномерен по D. Начальная ориентация независима и симметрична. Training 24 пути с seed 202701. Validation 96 путей с seed 202702. Независимый тест 1200 путей с seed 202703. В каждом семействе до четырёх настроек передаются на validation. Дробные лимиты рабочего объёма переведены в сетку 0.01.

Сначала отсев по жёстким условиям. Затем Recovery Rate, CVaR99, CVaR95, DD, средний PnL, расходы и время восстановления. Параметры не выбираются на независимых путях. Номинальный фильтр индикаторов дополняется индукцией гейта. Стресс-профили и независимая выборка используются для сравнения после отбора. Для Cmax<$29 невозможность обязательной ликвидации следует из денежного контракта без перебора. Для Bmax=$58 при доступном неблагоприятном переходе любая гарантированно допустимая политика имеет вероятность восстановления 0.

Парное различие считается по одним и тем же сценариям. Интервал Hoeffding 95% применяется к разности индикаторов в [−1,1] и консервативен. Для отдельной частоты используется Wilson 95%. При стресс-каталоге частота означает только долю проверенных примеров. Результаты для 4, 6, 8 и 12 событий фиксируют horizon вместе с параметрами. Сравнительный тест для выбранных политик может использовать календарь разной длины как часть самой политики.
