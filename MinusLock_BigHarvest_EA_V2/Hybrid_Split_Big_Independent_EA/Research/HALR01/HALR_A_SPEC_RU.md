# Сохранение исходной позиции

A1 фиксирует нижний предел убыточного билета на 1.00 лота. Для смещения Net сначала сокращает доступную противоположную ногу, затем открывает рабочую позицию в пределах лимитов. Движение в сторону прибыльного исходного билета может требовать нового входа, когда сокращение исходного проигравшего запрещено.

A2 снижает допустимый остаток. Первый сигнал позволяет частично ликвидировать исходный убыточный билет и перестроить Net. Сохранённый объём измеряется по исходному идентификатору.

A3 использует Original Core, рабочие BUY/SELL и целевой Recovery Net. При смене направления сначала нейтрализует Net. При достаточном накопленном движении рабочая нога допускает Harvest, который переводит mid-PnL в денежный журнал. Harvest Reserve представлен запасом бюджета перед действием. Число переключений ограничено.

Safe Preserve допускает аварийный выход. Strict Preserve может закончить горизонт с открытым Core и оценкой ликвидации. Эта оценка не учитывается как успешное закрытие.
