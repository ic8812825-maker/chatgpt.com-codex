# Закрытие и восстановление

Переход завершён после закрытия обоих исходных билетов. Закрытия исполняются с промежуточным контролем Net. В плоском состоянии денежный журнал по-прежнему содержит исходный убыток.

B1 разрешает одну направленную заявку. B2 разрешает ограниченную последовательность входов с новым уровнем отсчёта после остановки. B3 требует два последовательных наблюдения за порогом в одну сторону. B4 сокращает направленный объём при движении в свою сторону и может перейти во FLAT. Отказ входа расходует попытку. После незавершённого стопа следующий шаг повторяет выход.

Для нового объёма q при постоянном Net и отсутствии carry требуется благоприятное движение d > 58/q + spread + 2×commission + 2×slippage. Каждый завершённый ложный вход увеличивает дефицит на торговые расходы и отрицательную ценовую составляющую. Вариант K задаёт результат ожидания во FLAT.
