# Воспроизведение

Из каталога HALR01 с Python 3.11+ и стандартной библиотекой:

```sh
python -B -m unittest -v
python -B study.py
```

Полный прогон занимает несколько минут. CSV перезаписываются после вычислений. Детерминированный вывод можно проверить командой `git diff -- '*.csv'`. TEST_RESULTS.json также содержит версию интерпретатора.

Training — seed 202601, 80 путей. Validation — seed 202602, 160 путей. Список проверяемых кандидатов формируется только на training. Порядок выбора — отсутствие внутрисценарных нарушений, Recovery Rate, меньший CVaR95, большее среднее. Четыре лучших кандидата каждой семьи поступают на validation. Independent test — seed 202603, 1200 путей. Выбор бюджетной политики использует validation и отдельный полный шестишаговый тест ограничений. Тестовая частота не влияет на отбор. Для исчерпывающего расчёта обе ориентации имеют по 15625 путей. Для 88 стресс-постановок используются фиксированные матрица и правило адаптивного противника. На всех неадаптивных сценариях входные цитаты одинаковы. Лимит стратегии может быть строже общего максимума. Получить одинаковую длину цикла по всем стратегиям не требуется: ранний успешный выход и параметр горизонта являются частью политики.

Wilson 95% применяется к независимым синтетическим наблюдениям. Стресс-набор и полное конечное перечисление не требуют интервала выборочной неопределённости. CVaR — среднее верхнего хвоста убытков с дробной массой граничного наблюдения. P95/P99 — ранги с округлением вверх. Margin Stress — максимум Margin/Equity, DD — максимальный спад от пика. Execution Failures включает неполные, отклонённые и заблокированные модельными лимитами заявки. Незакрытые корзины оцениваются по резерву и отдельно маркируются: их PnL остаётся оценкой, а восстановление не засчитывается. Доля стресс-нарушений и статистический Recovery Rate относятся к разным генеральным совокупностям.

Проверка J Balanced из корня репозитория:

```sh
git fetch origin refs/pull/5/head
HALR=MinusLock_BigHarvest_EA_V2/Hybrid_Split_Big_Independent_EA/Research
LEGACY=$(mktemp)
git show "e507cb93a1e721f3b436baf9c6403d4d18715fd2:$HALR/UMLRS01/research.py" > "$LEGACY"
cp "$LEGACY" "$LEGACY.py"
python -B "$HALR/HALR01/audit_legacy.py" "$LEGACY.py"
rm "$LEGACY" "$LEGACY.py"
```

Для вывода о превосходстве M требуется улучшение парного восстановления при подтверждённом рисковом допуске и отсутствии ухудшения худшего PnL и CVaR95 относительно сравнимых альтернатив. Pareto Frontier показывает компромиссы на тестовой выборке и включает также точки без робастного допуска. Глобальная оптимальность по всем причинным стратегиям требует более широкого поиска.
