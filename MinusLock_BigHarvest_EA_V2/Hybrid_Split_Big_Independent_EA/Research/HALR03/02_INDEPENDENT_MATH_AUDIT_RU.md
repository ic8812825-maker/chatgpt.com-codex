# Независимый аудит

Oracle учитывает исполненную цену Bid/Ask и отдельный денежный расход по комиссии и carry. Исходные цены входа уже содержат спред. Оценка условного выхода суммируется непосредственно по каждой открытой ноге. В Ledger HALR-02 цены входа хранятся в mid, спред вынесен в расходы. Эквивалентность двух представлений проверена по каждому подтверждённому fill и по финальной оценке. Исходный замок даёт −$58, из которых $29 — исторические расходы, $29 — номинальный незаработанный резерв выхода.

AUDIT сопоставляет прямой и сжатый трёхшаговый перебор для обоих направлений и трёх политик. Контрольные поля включают количество, восстановления, минимум финала, минимум внутри, нарушения и остатки. При бюджете $100 номинальный порог одношагового Net равен 0.14 лота. 0.15 лота при 300 пунктах уже нарушает предел. UNKNOWN сохраняет остаток резерва открытия; повтор ключа идемпотентен. После запроса отмены поздний fill учтён по цене исполнения.
