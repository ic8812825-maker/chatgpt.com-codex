# Evidence index — пятая коррекция 3.1.5

- `baseline.log`: исходные воспроизведённые failures.
- `exact_probe_results.log`: expected/actual typed reason каждого probe.
- `mutation_kill_matrix.log`: fault trace, blockers и target каждой mutation.
- `causal_audit.log`, `source_guard.log`, `final_validator.log`: непосредственные executable outputs.
- `standalone_failure_manifest.txt`: точный baseline-набор.
- `verification.log`: pre-fresh-clone totals и статус.
