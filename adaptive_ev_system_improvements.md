# Предлагаемые дальнейшие улучшения (после текущей реализации)

1. Вынести параметры режима в внешнюю конфигурацию (YAML/JSON) + версионирование наборов.
2. Добавить комиссию/проскальзывание/латентность/финансирование в `Cost` и критерий PASS.
3. Ввести walk-forward валидацию по временным блокам и out-of-sample контроль.
4. Добавить CVaR/Expected Shortfall в критерий оптимизации вместо только `equity`.
5. Реализовать стресс-тесты с кластерными гэпами и последовательными шоками.
6. Добавить автоматический stop-trading триггер по ликвидности (spread/depth anomalies).
7. Перевести FSM на вероятностную модель переходов (байес/HMM).
8. Добавить портфельный уровень ограничений (корреляции инструментов и общий риск-кап).
9. Собирать и хранить детальный трейд-лог для post-mortem анализа.
10. Включить CI-прогон тестов и контроль регрессий параметров.
