# ALE /right — следующий шаг на утверждение

## Цель следующей итерации
Сделать **строгий контракт SAFE-фазы и инвариантов I1–I7** машинно-проверяемым в CI, чтобы любые будущие рефакторинги не ломали архитектуру двух потоков BUY/SELL.

## Почему это следующий шаг
Текущая база уже содержит:
- централизованный `CALRiskConfig`;
- детерминированный `CALDeterministicRunner`;
- базовые regression-оракулы.

Следующий логичный шаг — зафиксировать **формальные контракты поведения** как отдельный тестовый слой, чтобы:
1. поймать скрытые архитектурные регрессии раньше;
2. исключить «тихое» ослабление SAFE-ограничений;
3. обеспечить стабильность при расширении до N потоков.

---

## Предложение: Iteration “Contract Lock”

### 1) Новый тестовый модуль
Добавить:
- `Experts/VirtualPanel/right/tests/TestALEContracts.mqh`

Назначение: проверять не только numeric output, но и **контрактные правила системы**.

### 2) Контрактные тесты (обязательные)

#### C1. SAFE non-bypass
После входа в SAFE:
- `AddVirtual(...) == false`
- `BuildGrid(...) == false`

#### C2. SAFE state legality
- `SAFE -> EXPANSION` запрещён.
- Разрешены только переходы, разрешённые `CALStateMachine`.

#### C3. Additivity hard-check
На фиксированном сценарии:
- `TotalPnL == buy.pnl + sell.pnl`
- `NetDeltaTotal == buy.net_delta + sell.net_delta`
- `NetExposureTotal == buy.exposure + sell.exposure`

Точность: `1e-10`.

#### C4. Risk monotonicity hard-check
Для набора лотов `L1 < L2 < L3`:
- `Margin(L1) < Margin(L2) < Margin(L3)`

#### C5. Deterministic reset equivalence
Одинаковый сценарий до/после `Reset()`:
- совпадают `pnl`, `delta`, `margin`, `worst_dd`, `safe_active`.

#### C6. Config guardrail
Невалидные конфиги (`k*growth_g >= 1`, `dd_prob_limit>1`, `initial_equity<=0`) должны отклоняться `IsValid()==false`.

### 3) Критерии приёмки
Итерация считается принятой, если:
- `TestALEContracts` проходит полностью;
- существующие `TestALE`, `TestALERegression`, `TestGeometry`, `TestRisk` не деградируют;
- ни один публичный путь не позволяет открыть позицию при SAFE.
