# Предложения по улучшению Adaptive EV (дорожная карта)

## Приоритет P0 (обязательно до масштабирования)
1. Добавить издержки исполнения в расчет (`commission`, `slippage`, `swap`, `latency`).
2. Добавить stop-trading блок по аномальному spread/depth.
3. Ввести протокол обязательного ESCAPE-аудита (кто/когда/почему).

## Приоритет P1 (повышение устойчивости)
1. Walk-forward + out-of-sample валидация на исторических данных.
2. Стресс-тесты с гэпами/кластерными шоками.
3. Автоподбор диапазонов `k_min/k_max/lambda` по инструментам.

## Приоритет P2 (операционная зрелость)
1. Вынести параметры режимов в версионируемый YAML/JSON профиль.
2. Добавить журнал отклонений «рекомендовано vs исполнено».
3. Добавить CI-проверки на регрессию формул и контроль целостности .xlsx.

## Метрики приемки
- `all_positive=true` в full-cycle на расширенном наборе режимов.
- Ни одного нарушения ESCAPE-протокола.
- Стабильный положительный net edge после учета издержек.
