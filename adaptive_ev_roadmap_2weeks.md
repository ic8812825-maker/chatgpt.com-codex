# Roadmap на 2 недели: Python-стенд + Excel-калькулятор

## Неделя 1
### День 1-2 — Мульти-цикловый тестовый контур
- Внедрить `run_full_cycle_tests.py` для 20 полных прогонов по каждому режиму рынка.
- **Критерий приемки:** pass_rate >= 80% и avg_equity > 0 для всех сценариев.

### День 3-4 — Устойчивость параметров
- Прогнать чувствительность по gamma/step/alpha (локальная сетка).
- Выбрать набор с минимальным разбросом max_drawdown.
- **Критерий приемки:** ни один сценарий не уходит в отрицательный avg_equity.

### День 5-7 — Контроль риска в Excel
- Добавить в калькулятор коэффициент режима (0.5..2.0), влияющий на рекомендованный лот.
- **Критерий приемки:** при stress-коэффициенте 0.5 рекомендуемый лот снижается минимум на 50%.

## Неделя 2
### День 8-10 — Проверка исполнения и дрейфа
- Добавить отдельный журнал расхождения «рекомендованный лот vs исполненный». 
- **Критерий приемки:** есть сводка по 100+ шагам без пропусков.

### День 11-12 — Ужесточение stop-правил
- Ввести stop-trading по маржинальной нагрузке и fail survival в Excel и Python.
- **Критерий приемки:** в stress-режиме новые циклы блокируются автоматически.

### День 13-14 — Финальная приемка
- Повторить полный 20-цикловый прогон после всех правок.
- **Критерий приемки:** all_positive=true, обновленный отчет и архив.
